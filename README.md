Pizza Sales Analysis

The Pizza Sales Analysis project focuses on analyzing pizza sales data to identify business trends, understand customer purchasing behavior, and generate actionable insights to improve business performance.

This project uses SQL, Microsoft Excel, and Power BI to perform data analysis, data cleaning, and visualization. The analysis helps understand sales performance, popular pizza categories, customer preferences, and revenue trends.

🎯 Project Objectives
Analyze overall pizza sales performance.
Identify the best-selling and least-selling pizzas.
Understand sales trends across different days and months.
Analyze revenue and order patterns.
Identify the most popular pizza categories and sizes.
Generate meaningful business insights using interactive dashboards.
🛠️ Tools & Technologies
SQL: Data querying, aggregation, and business analysis.
Microsoft Excel: Data cleaning, preparation, and analysis.
Power BI: Interactive dashboards and data visualization.
